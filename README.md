# Karaoke Sync

カラオケ店でDAM・JOYSOUNDの採点機能を使いながら、イヤホンで本人歌唱を聴いて歌うための練習支援アプリです。

## Ver.0.1

### 実装済み機能

- YouTube IFrame APIによる動画再生
- 動画の再生位置保存
- 保存位置からの再生
- マイク入力取得
- 音量検知
- 音検知による自動再生
- 検知補正（±0.1秒）

### 検証結果

- Rick Astley：再生可能
- ゆず「表裏一体」：再生可能
- 「LOSER」：再生可能
- ライラック公式MV：再生不可
- ライラック Topic版：再生不可

YouTube動画は動画ごとに埋め込み可否が異なるため、再生可能な動画を利用する方針とします。
