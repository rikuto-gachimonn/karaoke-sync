# YouTube動画タイトルの自動取得

## 方式と確認結果（2026-10-19）

公式YouTube oEmbedのJSONをブラウザから直接fetchする。APIキー・認証情報・追加ライブラリ・サーバー処理は不要。動画IDだけを正規watch URLに組み立てて送信し、資格情報を送らず、参照元URLも送らない。マイク音声・曲リスト・診断ログは送信しない。

- 読み取り専用HTTP検証: wVYBpKEVLxQで200とtitleを取得。Originを https://example.netlify.app に指定すると、Access-Control-Allow-Originに同じOriginが返った。これは模擬Originであり、実Netlifyサイトの検証ではない。
- PCの実ブラウザ: localhost上の登録フォームに共有URLを入力し、直接CORS fetchによるタイトル自動入力の成功を確認。登録保存やマイク起動は行っていない。
- HTTPSエンドポイントなのでHTTPSサイトから混在コンテンツにならない。現在の配信ヘッダーに取得を遮断するCSPはない。将来CSPを導入する場合はconnect-srcに https://www.youtube.com を検討する。
- 実Netlifyサイト・iPhone Safari・コンテンツブロッカー・カラオケ店Wi-Fiでは未確認。CORS応答やネットワーク条件は将来変わり得る。取得成功は動画の実在継続、再生・埋め込み許可を保証しない。

参照: [YouTubeのoEmbed登録情報](https://oembed.org/providers/youtube)、[Netlify手動デプロイ](https://docs.netlify.com/deploy/create-deploys/)、[Netlify Functionsの導入](https://docs.netlify.com/build/functions/get-started/)。Functionsはビルド連携・CLI/API等のデプロイが必要になるため、現行のdistのみのドラッグ＆ドロップに追加していない。契約・課金・Privateアクセス設定は変更していない。

## 操作と保護

「曲管理」でYouTube URLまたは動画IDを入力する。形式が有効になってから650ms入力が落ち着いた時点で取得し、曲名へ入力する。同じ動画の共有パラメーター変更では再通信しない。取得中表示と8秒の期限を設け、失敗時は手入力できる。削除・非公開・埋め込み制限・通信障害・レート制限などで取得できない場合がある。具体的な失敗原因はブラウザから断定しない。

手動編集した曲名（空欄への編集も含む）は自動上書きしない。自動入力した名前のみ、別動画への変更時に消して再取得する。古いリクエストは中断し、世代番号も照合して遅着結果を無視する。生のタイトルを加工せず使うが、既存の曲名上限200文字を超える場合は手入力へ案内する。

既存曲編集では自動取得しない。「タイトルを再取得」を明示操作し、現在の曲名の置き換え確認に同意した場合だけフォームへ反映する。保存済み曲は「曲情報を更新」まで変更しない。取得中に手入力するとそちらを優先する。通信に失敗しても重複チェック・手動登録は従来どおり使える。

保存データ構造・同期設定・バックアップ形式・YouTubeプレイヤー・マイク制御は変更しない。動画IDと既存titleフィールドを保存する。

## ユーザーが後で再デプロイする場合

1. 必要なら既存サイトの曲リスト・同期設定をJSONでバックアップする。
2. pnpm.cmd test、pnpm.cmd typecheck、pnpm.cmd buildを実行する。
3. Netlifyの**既存サイト**のDeploys画面へ、生成されたdistフォルダを手動アップロードする。今回は実施していない。
4. 既存のPrivateアクセス制限が維持されていることを確認する。別の公開サイトを新規作成しない。
5. iPhone Safariで新規URL貼り付け、手入力保護、編集時確認、失敗時手入力、重複登録通知を確認する。
6. 同一URLなら既存ブラウザ保存領域を利用する。ドメインが変わる場合は別領域なのでJSONで明示的に移行する。

追加のFunctions・APIキー・有料サービスは不要。ただしNetlify既存契約の利用枠や料金そのものを保証するものではない。
